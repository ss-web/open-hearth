# Открытый очаг

Эталонная реализация открытого некоммерческого фонда поддержки христианских семей. Сайт показывает миссию, шкалу выплат, публичную очередь, проверяемую жеребьёвку и открытую казну. Реестр учебный: юридическое лицо не зарегистрировано, пожертвования не принимаются.

Другие имена, которые рассматривались: Фонд поддержки христианской семьи, Колыбель завета, Дом Агапэ, Публичный семейный завет. Выбрано «Открытый очаг» / Open Hearth / Բաց օջախ: коротко на трёх языках и сразу говорит о прозрачности.

## Запуск

```bash
npm install
npm run verify
npm run dev
```

Сайт откроется на http://localhost:3000. Без PostgreSQL он читает встроенный учебный реестр и пишет об этом в красной полосе.

С базой (порт 5433, чтобы не задеть другой PostgreSQL на 5432):

```bash
docker compose up -d
npm run db:setup
npm run dev
```

`db:setup` создаёт схему, заливает тот же реестр и проверяет, что роль сайта не читает таблицу `application_private`.

Переменные окружения — в `.env.example`.

## Проверка

`npm run verify` пересчитывает жеребьёвку и сверяет тождество казны. Оно должно завершаться строкой `verify: ok`.
